# MotorSense Backend

Servicio API encargado de la gestión de diagnósticos y persistencia de datos.

## Cómo ejecutar el servidor

Para iniciar el servidor de desarrollo de Django, sigue estos pasos:

1. **Activa el entorno virtual:**
   - **Windows:** `.venv\Scripts\activate.bat`
   - **Mac/Linux:** `source .venv/bin/activate.bat`

2. **Inicia el servidor:**
   ```bash
   .venv\Scripts\python.exe manage.py runserver
