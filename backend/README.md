# MotorSense Backend

Servicio API encargado de la gestión de diagnósticos y persistencia de datos.

## Configuración del Entorno
1. Crea el entorno virtual:
   `python -m venv .venv`
2. Actívalo:
   - Windows: `.venv\Scripts\activate.bat`
   - Linux/Mac: `source .venv/bin/activate`
3. Instala las dependencias:
   `pip install -r requirements.txt`

## Ejecución
- Inicia el servidor: `python app.py` (o tu comando correspondiente).
